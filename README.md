# Smart Greenhouse

A web dashboard to monitor and control a smart greenhouse remotely:
temperature, humidity, soil moisture, light, and irrigation.

## Features
- Live sensor readings
- Remote control of irrigation and fans
- Automatic mode based on soil moisture
- Reading history and charts
- Light and dark mode

## Tech stack
- HTML, CSS, JavaScript, Bootstrap 6 (alpha)
- PHP and MySQL (next phase)
- Laravel (final phase)

## How to run
1. Clone the repository.
2. Open the folder in VS Code.
3. Run `index.html` with the Live Server extension.
